            Sheet 13 — Surface Cut
            
Cross-Process Offline Localization Architecture

          

          Zero Cloud API Cost
        

        

          Argos Translate runs OpenNMT / CTranslate2 neural machine translation models in Python, which cannot run inside Unity's Mono/IL2CPP AppDomain directly. ArgosTranslateTool bridges this OS process boundary deterministically: harvesting TMP_Text strings from the scene hierarchy, serializing them via a dependency-free UTF-8 JSON codec over stdin, and writing the translated arrays directly into Unity's StringTableCollection assets.
        

        

          

            
Python Exe Resolution

            
Auto-detects project-local .argos_venv on Windows & macOS before system paths.

          

          

            
Dependency-Free JSON

            
Custom C# JSON string array serializer/parser with full \uXXXX surrogate support.

          

          

            
Reflection Window Sync

            
Invokes LocalizationTablesWindow.ReloadTables() so open Editor windows repaint live.

          

        

      


      

        Runtime & Font Pipeline
        
Verified Unity Implementation Details

        

          

            Idempotent Scene Harvesting (ArgosIgnoreLocalization):
            Skips language-switcher button captions and checks existing LocalizeStringEvent bindings so re-harvesting never duplicates keys.
          

          

            Dynamic OS Font Fallback (DemoFontFallback.cs):
            Appends OS CJK (Yu Gothic / Hiragino Sans) and Devanagari (Nirmala UI / Kohinoor) fallback TMP_FontAsset instances at runtime and cleans them up in OnDestroy.
