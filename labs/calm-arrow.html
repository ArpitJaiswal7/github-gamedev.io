Dual-Engine Architecture

How Both Web & Unity Engines Align

Identical algorithms implemented natively in HTML5 Canvas 2D and Unity C#.

1. Solvability Generator

Eliminates unsolvable deadlocks by carving arrows backward in reverse solve order using Warnsdorff degree heuristics. The first arrow peeled is always 100% free to escape.

JS Generator & C# SolvableShapeGenerator

2. Dynamic Board Masking

High-density 2D matrix masking (activeMask[x][y]) with automatic camera & canvas bounding to frame shapes tightly with header padding.

Canvas Frame & C# ShapeGridSystem

3. Smooth Chevron Arrows

Continuous smooth rounded body lines with sampled color gradients and directional chevron arrowheads (Up, Down, Left, Right).

Canvas Path & C# LineRenderer

4. Rebound & 3-Lives System

Clicking a blocked arrow probes forward grid-by-grid to the obstacle, plays a tactile collision bump, deducts 1 life with toast notifications, and snakes backward to its exact original grid set.

Path History Snapback & C# Coroutine
