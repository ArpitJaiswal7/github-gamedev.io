🛠️ Interactive API Helper Methods (PuzzleServerAPI)

Click any helper method below to execute it live against the backend server and inspect the response used by Unity WebGL (NativeImageBridge.jslib) and the Web version:

1. PuzzleServerAPI.getPublishedImageUrls()

Returns the flat string[] array of all currently published puzzle image URLs on the server.

2. PuzzleServerAPI.getPublishedPuzzles()

Returns the full PuzzleManifestResponse JSON (version, urls, puzzles) consumed by Studio.NativeImagePipeline.

3. PuzzleServerAPI.fetchPuzzleImageData(url)

Fetches the first published URL via CORS, decodes & square-crops it on an OffscreenCanvas (matching NativeImageBridge.jslib), and returns raw Uint8Array bytes + DataURL.

📋 Usage in Web & Unity WebGL Bridge 
// 1. Get all published image URLs
const urls = await PuzzleServerAPI.getPublishedImageUrls(
  "http://localhost:4200"
);

// 2. Fetch & decode 1080x1080 square bytes via Bridge
const imgData = await PuzzleServerAPI.fetchPuzzleImageData(
  urls[0],
  { targetSizePx: 1080, mimeType: "image/jpeg" }
);
