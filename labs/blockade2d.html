Architecture & Technical Highlights

Unity 6000.3.14f1 • C# Standalone Engine

Pure Domain-Driven Core (`Blockade2D.Core`)

Zero Unity dependencies in core logic. Board model, jump mechanics (orthogonal jumps, jump-over-opponent, diagonal jump deflection), BFS pathfinding, and command history compile cleanly to a standalone .NET Standard DLL with 100% test coverage.

Clean Architecture 14 Unit Tests

BFS Non-Trapping Fair Play Rule

Every proposed blocker placement simulates wall addition and runs a dual Breadth-First Search for both Player 1 and Player 2. Any wall placement that completely walls off either player from their goal row is instantly rejected, shaking the preview in red.

O(V + E) BFS Search Wall Conflict Matrix

Mobile Touch Offset (+Y Floating Preview)

Eliminated touch finger obstruction on mobile and tablet screens. While dragging blockers, the preview automatically projects +1.6 world units above the finger/input coordinate, snapping cleanly to grid intersections so the target is always 100% visible.

Hold & Drop UX Dynamic UI Scaling
