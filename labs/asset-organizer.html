System Architecture & Editor Hooks

Editor-Only Assembly

Built as a modular Unity Package (com.arrowstrike.asset-organizer) with zero runtime footprint. Uses O(1) GUID hash lookups inside EditorApplication.projectWindowItemOnGUI and native OS shell interop for multi-asset selection in Windows Explorer and macOS Finder.

Project Window Hooks

Context menu (Assets/Asset Organizer), Ctrl+Win+P Win32 key poll, and top-right C/R hover tag-button.

PinnedAssetsStore

Per-project JSON store in ProjectSettings/. Tracks groups, colors, GUIDs, sizes & duplicate-pin prevention.

OSFileExplorerUtility

Calls Win32 SHOpenFolderAndSelectItems & macOS osascript to highlight multiple files in a single OS window.

AssetChangeWatcher: AssetPostprocessor auto-heals paths on move/rename/delete. 0 Bytes Runtime Memory
Under The Hood

Core Engineering Highlights

1. Collaborative Badge + Hover Button (C / R)

Renders procedural anti-aliased SDF circular badges in both Tile and List views. Entering the top-right corner rect transforms the badge into an interactive C (Copy full drive path) or R (Reveal) button without losing multi-selection.

2. Multi-Asset Single-Window Explorer Reveal

Unity's built-in RevealInFinder opens N separate windows for N files. We P/Invoke shell32.dll!SHOpenFolderAndSelectItems with child ITEMIDLIST pointers on Windows and batch POSIX file lists in Finder on macOS.

3. Build Report Inspired Inspection & Drag-and-Drop

Displays formatted folder + bold filename paths, asset types, disk byte sizes, percentage breakdown, live color pickers before each group name, group drag-reordering, and instant Project Window ping.
